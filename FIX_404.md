# Fix GitHub Pages 404 Error

## Issue

GitHub Pages is enabled but showing 404. This means the deployment hasn't completed yet or needs to be configured correctly.

## Solution

### Option 1: Use GitHub Actions (Recommended)

1. **Go to Repository Settings**:
   https://github.com/upendra-manike/kora/settings/pages

2. **Change Source to GitHub Actions**:
   - Under "Build and deployment"
   - **Source**: Select "GitHub Actions"
   - Save

3. **Trigger the Workflow**:
   - Go to: https://github.com/upendra-manike/kora/actions
   - Find "Deploy to GitHub Pages" workflow
   - Click "Run workflow" → "Run workflow"
   - Or wait for the next push (it should trigger automatically)

4. **Wait 2-3 minutes** for deployment

5. **Visit**: https://upendra-manike.github.io/kora/

### Option 2: Use Branch Deployment (Alternative)

If GitHub Actions doesn't work:

1. **Go to Repository Settings**:
   https://github.com/upendra-manike/kora/settings/pages

2. **Configure**:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/docs`
   - Save

3. **Wait 1-2 minutes**

4. **Visit**: https://upendra-manike.github.io/kora/

## Verify Files Are Present

The files should be at:
- `docs/index.html` ✅

- `docs/script.js` ✅
- `docs/404.html` ✅

All files are committed and pushed to GitHub.

## Check Deployment Status

1. **GitHub Actions**:
   https://github.com/upendra-manike/kora/actions
   - Look for "Deploy to GitHub Pages"
   - Should show green checkmark when complete

2. **Repository Settings → Pages**:
   https://github.com/upendra-manike/kora/settings/pages
   - Should show deployment status
   - Should show the site URL

## Troubleshooting

If still getting 404:

1. **Wait 5 minutes** - First deployment can take time
2. **Check Actions tab** - Ensure workflow completed
3. **Hard refresh browser** - Cmd+Shift+R or Ctrl+Shift+R
4. **Try incognito/private window** - Rule out cache issues
5. **Check URL case** - Should be lowercase: `kora` not `Kora`
