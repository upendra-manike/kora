# Programming Language Name Suggestions

## Current Name: Kora

**Issues with "Kora":**
- May be confused with "Koa" (Node.js framework)
- Not immediately descriptive of the language's purpose
- Could be confused with other tools/libraries

---

## Suggested Names

### Category 1: Architecture-Focused Names

#### 1. **Stratum** ⭐ (Top Recommendation)
**Meaning**: A layer or level (perfect for domain/API/UI layers)
- ✅ Reflects architectural layering
- ✅ Professional and memorable
- ✅ Easy to pronounce
- ✅ Suggests structure and organization
- **Tagline**: "Build in layers, deploy as one"

#### 2. **Tier**
**Meaning**: A level or layer
- ✅ Simple, clear concept
- ✅ Reflects the three-tier architecture
- ⚠️ Might be too generic

#### 3. **Layer**
**Meaning**: A level or stratum
- ✅ Directly describes the architecture
- ⚠️ Very common word, might be hard to search

#### 4. **Stratify**
**Meaning**: To form or arrange in layers
- ✅ Action-oriented
- ✅ Unique
- ⚠️ Less memorable

## Naming Criteria Checklist

For each name, consider:

- ✅ **Memorability**: Easy to remember?
- ✅ **Pronounceability**: Easy to say?
- ✅ **Uniqueness**: Stands out from competitors?
- ✅ **Relevance**: Reflects language purpose?
- ✅ **Availability**: Domain, npm package, GitHub org available?
- ✅ **Trademark**: Can it be trademarked?
- ✅ **SEO**: Easy to search for?

---

## Rebranding Considerations

If changing the name:

1. **Update package.json**: `@stratum-lang/stratum` (or chosen name)
2. **Update npm package**: New package name
3. **Update GitHub**: Repository name
4. **Update documentation**: All references
5. **Update website**: Domain and branding
6. **Migration guide**: For existing users

---

## Domain Availability Check

Before finalizing, check:
- Domain name (.com, .dev, .io)
- npm package name
- GitHub organization
- Twitter/X handle
- Social media handles

## Final Recommendation

**Stratum** is the top choice because:
1. ✅ Perfectly describes the layered architecture
2. ✅ Professional and memorable
3. ✅ Unique in programming languages
4. ✅ Easy to pronounce globally
5. ✅ Good branding potential

**Tagline options:**
- "Build in layers, deploy as one"
- "Layered architecture, unified codebase"
- "From domain to UI, one language"

---

## Alternative: Keep "Kora" but Rebrand

If keeping "Kora":
- Emphasize it's "Kora Language" (not Koa framework)
- Use tagline: "Kora: Full-Stack, Type-Safe, Layered"
- Create distinct visual identity
- Clear differentiation in marketing
