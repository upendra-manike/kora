# Kora Language Roadmap

Long-term vision and development plan for the Kora programming language.

## Vision

**Kora is a full-stack programming language that enforces architectural discipline by default, compiling to TypeScript/JavaScript.**

## Current Version: 0.1.0

### ✅ Completed

- [x] Language grammar definition
- [x] Tokenizer/Lexer
- [x] Parser (AST generation)
- [x] Compiler (TypeScript output)
- [x] CLI tool
- [x] npm package published
- [x] GitHub repository
- [x] Documentation website
- [x] Sample projects (5 complete examples)
- [x] Basic error handling
