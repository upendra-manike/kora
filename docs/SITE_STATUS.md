## To Enable GitHub Pages

If the site is not yet live, enable it:

1. **Go to Repository Settings**:
   https://github.com/upendra-manike/kora/settings/pages

2. **Configure Pages**:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/docs`
   - Click **Save**

3. **Wait 1-2 minutes** for GitHub to build and deploy

4. **Visit**: https://upendra-manike.github.io/kora/

## Automatic Deployment

Once enabled, the site will automatically update when you:
- Push changes to `main` branch
- Update files in `docs/` directory

The GitHub Actions workflow (`.github/workflows/pages.yml`) handles this automatically.

## Troubleshooting

If the site doesn't load:

1. **Check GitHub Pages Settings**:
   - Ensure Pages is enabled
   - Verify branch is `main`
   - Verify folder is `/docs`

2. **Check GitHub Actions**:
   - Go to: https://github.com/upendra-manike/kora/actions
   - Look for "Deploy to GitHub Pages" workflow
   - Check if it completed successfully

3. **Wait a few minutes**:
   - First deployment can take 2-5 minutes
   - Subsequent updates are faster

4. **Clear browser cache**:
   - Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)

## Custom Domain (Optional)

To use a custom domain:

1. Add `CNAME` file in `docs/` with your domain
2. Configure DNS settings
3. Update GitHub Pages settings
