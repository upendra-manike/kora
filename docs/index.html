Kora

A full-stack programming language that compiles to TypeScript/JavaScript

Build UI and Backend together with architectural discipline by default. One language, three concerns, zero glue code.

Get Started GitHub npm

Why Kora?

🏗️

Architectural Boundaries

Enforced module boundaries. Illegal imports are compiler errors, not conventions.

🔒

Type Safety

Shared types across UI and Backend. Compile-time guarantees, no runtime surprises.

⚡

Zero Glue Code

No fetch boilerplate, no DTO duplication, no Swagger drift. The compiler handles it.

🚀

Standard Output

Compiles to standard TypeScript/JavaScript. Works with React, Next.js, Node.js.

📦

Convention Over Configuration

Sensible defaults. Less configuration, more building.

🔄

Eject Anytime

Output is standard code. Debug, modify, or eject to pure TypeScript anytime.

🎨

CSS Support (Coming Soon)

Scoped styles, global themes, responsive design. Type-safe CSS with component-level isolation.

1

Installation & Setup

Get Kora installed and create your first project:

# Install globally
npm install -g @kora-lang/kora

# Create a new project
kora new my-app

# Or compile a single file
kora compile hello.kora -o hello.ts

✅ Kora compiles to standard TypeScript/JavaScript that works with React, Next.js, and Node.js.

2

Define Your Domain

Start by defining your data models in a domain module:

module domain Post {
  type Post {
    id: UUID
    title: String
    content: String
    author: Author
    tags: String[]
    published: Boolean?
    createdAt: Date
  }

  type Author {
    id: UUID
    name: String
    email: Email
  }
}

✅ Domain modules enforce clean architecture. They can only import from other domain modules.

3

Create API Endpoints

Define your backend APIs with type-safe input/output:

api getPost {
  input {
    id: UUID
  }

  output Post

  handler {
    const post = PostRepo.findById(id)
    if (!post) {
      throw Error("Post not found")
    }
    return post
  }
}

api createPost {
  input {
    title: String
    content: String
    authorId: UUID
  }

  output Post

  handler {
    return PostRepo.create({
      title,
      content,
      authorId,
      createdAt: Date.now()
    })
  }
}

✅ APIs can import from Domain modules. The compiler generates API routes, validation, and error handling.

4

Build UI Pages

Create pages that automatically connect to your APIs:

page PostDetail {
  load(id: UUID) -> Post

  view(post: Post) {
    

      
{post.title}

      
{post.content}

      
By {post.author.name}

      {post.tags.map(tag => (
        {tag}
      ))}
    

  }
}

✅ Pages can import from Domain modules. The compiler generates React components with automatic API connections.

5

Add Styling

Style your components with scoped CSS:

page StyledPost {
  styles {
    .container {
      padding: 2rem;
      max-width: 800px;
      margin: 0 auto;
    }
    
    .title {
      font-size: 2rem;
      color: #333;
      margin-bottom: 1rem;
    }
    
    .tag {
      display: inline-block;
      padding: 0.25rem 0.5rem;
      background: #007bff;
      color: white;
      border-radius: 4px;
      margin-right: 0.5rem;
    }
    
    @media (max-width: 768px) {
      .container {
        padding: 1rem;
      }
    }
  }

  view(post: Post) {
    

      
{post.title}

      
{post.content}

    

  }
}

✅ Styles are scoped to components. Use global styles for theme variables and base styles.

6

Compile and Deploy

Build your application:

# Check for errors
kora check src/domain/post.kora

# Compile to TypeScript
kora compile src/domain/post.kora -o dist/post.ts

# Build entire project
kora build

# Start development server
kora dev

✅ Import generated code in your Next.js/React app. Output is standard TypeScript - debug and modify as needed!

api createUser {
  input {

    }
    return UserRepo.save(user)
  }
}

✅ Same Kora code works with MongoDB, PostgreSQL, MySQL, or Prisma. Just implement the repository!

Read Operations

// Get single user
api getUser {
  input { id: UUID }
  output User
  handler {
    return UserRepo.findById(id)
  }
}

// List users with filters
api listUsers {
  input {
    role: UserRole?
    minAge: Number?
    search: String?
    limit: Number?
  }
  output User[]
  handler {
    return UserRepo.findByFilters(role, minAge, search, limit)
  }
}

✅ Query filtering handled in repository. Kora ensures type safety.

Update User

api updateUser {
  input {
    id: UUID
    name: String?
    email: Email?
    age: Number?
  }
  output User
  handler {
    let user = UserRepo.findById(id)
    if (name != null) user.name = name
    if (email != null) user.email = email
    if (age != null) user.age = age
    user.updatedAt = Date.now()
    return UserRepo.save(user)
  }
}

✅ Partial updates. Type-safe field updates.

Delete User

api deleteUser {
  input { id: UUID }
  output Boolean
  handler {
    UserRepo.delete(id)
    return true
  }
}

✅ Simple delete. Repository handles database-specific logic.

Security & Routing - Interactive Demo

Complete security implementation with authentication, authorization, and route protection

Authentication (Login)

api login {
  input {
    email: Email
    password: String
  }

  output {
    user: User
    token: String
  }

  handler {
    let user = UserRepo.findByEmail(email)
    let isValid = PasswordHash.verify(password, user.passwordHash)
    
    if (!isValid) {
      throw Error("Invalid credentials")
    }

    let token = JWT.generate({
      userId: user.id,
      role: user.role
    }, expiresIn)

    return { user, token }
  }
}

✅ Secure password verification, JWT token generation, session management.

Authorization (Role-Based)

api adminAction {
  @requireAuth
  @requireRole(ADMIN)

  input { action: String }
  output { success: Boolean }

  handler {
    let authContext = Request.getAuthContext()
    
    if (authContext.role != UserRole.ADMIN) {
      throw Error("Admin access required")
    }

    // Admin-only logic
    return { success: true }
  }
}

✅ Role-based access control. Decorators enforce authorization automatically.

Route Protection

// Public route
page Login {
  @public
  view() { /* Login form */ }
}

// Protected route
page Dashboard {
  @requireAuth
  load() -> User
  view(user: User) { /* Dashboard */ }
}

// Role-based route
page AdminPanel {
  @requireAuth
  @requireRole(ADMIN)
  load() -> AdminData
  view(data: AdminData) { /* Admin panel */ }
}

✅ Routes automatically protected. Unauthorized users redirected to login.

API Security

// Public API
api getPublicData {
  @public
  output Post[]
  handler {
    return PostRepo.findPublic()
  }
}

// Protected API
api getProfile {
  @requireAuth
  output User
  handler {
    let authContext = Request.getAuthContext()
    return UserRepo.findById(authContext.userId)
  }
}

// Permission-based API
api deletePost {
  @requireAuth
  @requirePermission(DELETE_POSTS)
  input { id: UUID }
  output Boolean
  handler {
    PostRepo.delete(id)
    return true
  }
}

✅ APIs protected with decorators. Middleware handles token verification automatically.

Traditional vs Kora

Traditional Stack

  • ❌ TypeScript interfaces (duplicated)
  • ❌ API route handlers (manual)
  • ❌ Fetch calls in components
  • ❌ Type definitions everywhere
  • ❌ Validation logic scattered
  • ❌ ~40 lines per feature

Kora

  • ✅ Types defined once
  • ✅ APIs auto-generated
  • ✅ No fetch boilerplate
  • ✅ Types shared automatically
  • ✅ Validation built-in
  • ✅ ~10 lines per feature
